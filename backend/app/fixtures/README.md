## Notes

- Every document carries the footer `SYNTHETIC DEMO DOCUMENT — NOT A REAL CERTIFICATE`, legible at
  projector distance (`NFR-08`).
- Mismatch/unregistered override values (the specific alternate name, date, etc.) are free choices —
  `docs/category-schemas.md` only requires that they differ from the registry fixture in the stated
  field, not that they take any particular value.
- No real personal data, real institution name, real identifier, or real emblem appears anywhere in
  this directory or in the scripts that generate it (`AGENTS.md` Rule 7).

## Known shim — read before modifying `seed_registry.py`

Task 02's `registry_repo` doesn't exist in this checkout yet, so `seed_registry.py` currently talks
to SQLite directly through a minimal, self-contained SQLAlchemy model defined inside that file. This
was an explicit project-lead decision, not an invented contract. Once Task 02 lands with a real
model/repo, replace the shim (marked clearly at the top of `seed_registry.py`) and re-run the tests
to confirm behaviour is unchanged. The default DB path assumption (`backend/data/app.db`) should also
be confirmed against `docs/configuration.md` once available.
